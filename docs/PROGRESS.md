## С чего продолжить
P3.1 и далее — гидравлика в сцене. Предлагаемый порядок:
1. Элементы гидропривода как детали новой группы `hyd` в `model.js` (бак, насос, предохранительный клапан, распределитель 4/3, дроссель, обратный клапан, цилиндр, гидромотор) с портами в собственных координатах — по образцу `jointsOf()` в `domains/tmm/scene.js`.
2. Массив `pipes` в сцене: `{ id, a: [partId, port], b: [partId, port], pts: [[x, y, layer]…], d, kind: pressure|return|drain|pilot, fluid }`; формат v5 с миграцией. Прокладка: клик по порту, клики по промежуточным точкам, клик по второму порту. Длина — по ломаной с учётом разности слоёв (`LP` на слой).
3. `src/js/domains/hydro/scene.js`: сборка `net` для `hydroSolve()` из деталей и труб (узел = порт или группа портов, соединённых трубой нулевого сопротивления / тройником), хранение последнего решения как начального приближения, вызов из `solve()` после баланса мощности. Насос берёт скорость с вала (`p.w`), его момент `Δp·q/(2π·η)` идёт в баланс как нагрузка (как `p.mb` у кривошипа).
4. Цилиндр: шток — «движущаяся стойка» для рычажного механизма (как толкатель кулачка), положение интегрируется по скорости из решения сети в кадре анимации; упоры — `stop` в сети.
5. Отрисовка: обозначения по ГОСТ 2.781/2.782 в `scheme.js`, линии труб по ГОСТ 2.784 (напорная сплошная, слив — сплошная, дренаж — штрих, управление — штрих), анимация бегущими штрихами `lineDashOffset` со скоростью, пропорциональной расходу, цвет по давлению и легенда.
6. Демо-сцена 3 (стрела экскаватора), затем фаза 4.
Проверка: `npm test` (85 тестов), `node scripts/smoke.mjs shot.png`.
